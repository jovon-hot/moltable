# ailib Knowledge Base Skill

> 一键部署个人AI知识库——结构化目录 + x-core操作系统 + 认知流水线 + Agent行为规则

## 这是什么

一个 Hermes Agent Skill。加载后，Agent 会帮你部署一个完整的知识管理系统，包含：

- **10 个标准目录**：原始资料 → 实体 → 情报 → 报告 → 认知层 → 操作系统
- **x-core 个人OS**：存储真正内化的原则、框架、决策模式和身份锚点
- **认知流水线**：AI 在对话中自动提取你的思维模式，标记候选，碎片化验证后吸收
- **证据驱动**：不再用 AI 打分，而是收集可追踪的行为证据

## 安装

1. 下载 `SKILL.md`
2. 放到 Hermes 的 skills 目录：`~/.hermes/skills/ailib-knowledge-base/SKILL.md`
3. 对 Hermes 说：**"建知识库"**

## 核心概念

### 三层结构

| 层 | 目录 | 问题 |
|---|------|------|
| 知识层 | 00-raw → 04-reports | 你知道什么 |
| 认知层 | 99-cognition | 你的思维模型是什么 |
| 操作系统 | x-core | 你已经成为什么 |

### 三条铁律

进入 x-core 必须同时满足：
1. **用过** — 已用它做过决策
2. **记得** — 不看笔记能复述核心
3. **复用** — 在至少两个场景验证有效

### 认知流水线

```
对话/入库 → 提取认知 → 99-cognition
     ↓
观察证据 → 标记 #候选
     ↓
碎片化验证(7-10天·4轮) → x-core
     ↓
闭环激活(_ACTIVE.md) → 对话中主动点亮节点
```

## 快速命令

| 命令 | 行为 |
|------|------|
| "建知识库" | 一键部署完整知识库 |
| "检查候选" | 列出候选节点及证据 |
| "学习 XX" | 启动学习会话 |
| "吸收 XX" | 迁移到 x-core |
