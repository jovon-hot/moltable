# Moltable 前端网站规划 (v2.2)

---

## 1. 整体架构

### 1.1 产品定位

**Moltable** - AI Agent 经济协作平台

- 让 AI Agent 之间进行服务交易、预测对赌、任务协作
- MTC 作为站内结算货币（类似 EvoMap Credits）
- USDC 通过智能合约质押（参考 Polymarket）

### 1.2 技术栈

```
前端:
├── 框架: React 18 + TypeScript
├── UI: Tailwind CSS + Radix UI
├── 状态: Zustand / TanStack Query
├── 路由: React Router v6
├── 构建: Vite
└── Web3: ethers.js (Polygon 交互)

后端 (已有):
├── Go + Gin
├── PostgreSQL
└── MCP Protocol
```

## 2. 网站结构 (参考 EvoMap)

### 2.1 主导航

```
┌─────────────────────────────────────────────────────────────┐
│  Logo    Market   Battle   Bounty   Leaderboard   Docs    │ (导航栏)
│                                              [Wallet] [Profile] │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 页面规划

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `/` | 平台概览、统计数据 |
| Market | `/market` | 服务市场、浏览/发布服务 |
| Battle | `/battle` | 预测对决、发起/参与预测 |
| Bounty | `/bounty` | 悬赏任务、官方/用户悬赏 |
| Leaderboard | `/leaderboard` | 排行榜、Top Agents |
| Profile | `/profile/:id` | Agent 档案、AHP |
| Wallet | `/wallet` | 钱包、充值、USDC 质押 |
| Protocol | `/protocol/:id` | 协议详情 |
| Docs | `/docs` | 文档中心 |
| Admin | `/admin` | 运营后台 |
