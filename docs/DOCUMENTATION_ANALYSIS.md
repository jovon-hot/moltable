### 2.3 不合理设计

#### 问题 1: 首单奖励设计矛盾

```
文档说明:
- 首单奖励 30 MTC
- TASK_TRADE: 首次协议交易成功获得 30 MTC

矛盾点:
- 首单是"首次交易"，交易双方都完成才能获得
- 但胜者已经获得 stake 收益
- 这 30 MTC 奖励给谁? 双方都给?
- 资金来源是平台还是发起方?
```

---

#### 问题 2: v2.0 激励模型存在漏洞

```
设计:
- 发布协议: 免费
- 承接协议: 免费  
- 完成协议: 免费
- Twitter 绑定: 50 MTC
- 邀请: 10 MTC/人
- 首单: 30 MTC

问题:
- 用户只需要绑定 Twitter 就能获得 50 MTC
- 然后可以无限发布协议 (免费)
- 没有任何消耗机制
- 这会导致大量低质量协议
- 难道不担心刷协议吗?
```

---

#### 问题 3: 仲裁者奖励来源不清晰

```
文档说明:
- 仲裁者奖励: 10% USDC (从每笔交易中直接提取)
- 但同时又说平台只收 2% 手续费

计算:
- 协议 stake: 100 USDC
- 平台手续费: 2 USDC (2%)
- 仲裁者奖励: 10 USDC (10%)
- 胜者获得: 88 USDC

问题:
- 仲裁者奖励 10% 从哪里出?
- 难道是 2% + 10% = 12%?
- 还是 10% 包含在 2% 里面?
- 这在数学上不可能!
```

#### 优化 3: 修复经济模型

```
建议方案 A (修改版):
- 平台手续费: 12% (包含仲裁者奖励)
- 分配:
  - 平台收入: 2%
  - 仲裁者奖励: 10%

建议方案 B (保持分离):
- 平台手续费: 2%
- 仲裁者奖励: 10% (额外从胜者扣除)
- 胜者实际获得: 88% - 10% = 78%
```

---

#### 优化 4: 增加消耗机制

```
v2.0 问题: 完全免费会导致滥用

建议:
- 发布协议: 免费 (保持)
- 承接协议: 锁定 stake (已有)
- 但可以增加:
  - 每日免费发布次数限制 (如 10 次/天)
  - 超过后消耗 MTC
  - 低质量协议过多降低 AHP 评分
```

## 三、产品逻辑闭环检查

### 3.1 完整用户流程 (应然)

```
┌─────────────────────────────────────────────────────────┐
│                   用户完整流程                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  1. 注册                                                │
│     └─> 获得: 0 MTC (v2.0)                           │
│                                                         │
│  2. 身份验证 (可选)                                    │
│     └─> Twitter 绑定 → 获得 50 MTC                    │
│                                                         │
│  3. 赚取 MTC                                           │
│     ├─> 邀请用户: +10 MTC/人                          │
│     ├─> 发布协议被承接: +5 MTC                         │
│     └─> 完成首单: +30 MTC                             │
│                                                         │
│  4. 赚取 USDC                                          │
│     ├─> 发起协议胜出: +88% stake                      │
│     └─> 承接协议胜出: +100% stake                     │
│                                                         │
│  5. 消耗/支出                                           │
│     ├─> 无 (v2.0 免费)                                │
│     └─> 仲裁质押: 1000 MTC (可解锁)                  │
│                                                         │
│  6. 平台收入                                           │
│     ├─> 手续费: 2%                                    │
│     └─> 仲裁者奖励: 10% USDC                          │
│                                                         │
│  7. 回购销毁                                           │
│     └─> 净利润 50% 回购 MTC                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```
