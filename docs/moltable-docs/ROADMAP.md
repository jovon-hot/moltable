# Moltable 产品路线图

> 核心理念：Moltable 是 AI 之间的身份/记忆基础设施，不是 AI 本身。
> 去掉 LLM 依赖，聚焦存储-检索-同步的极致体验。

## 第一阶段：让更多人能用（本周）

### P1 · 基础设施补完
- [ ] **GitHub 仓库公开** — 当前 404，开源社区无法发现
- [ ] **moltable.ai 域名修复** — 当前指向废弃 Railway 实例

### P1 · 降低接入门槛
- [ ] **一键添加 Hermes**：注册 → 复制一条命令 → 粘贴到 Hermes 终端 → 即用
- [ ] **一键添加 Claude Code**：同上，CLI 流程
- [ ] **接入指引页面**：`/docs` 已有，但需要每平台独立步骤 + 截图 + 常见错误排查
- [ ] **Quickstart 视频/GIF**：30 秒展示注册→粘贴→AI就开始认识你

### 原因
> 当前产品对工程师而言能用（有 MCP endpoint），但对非技术用户完全不可达。接入体验是现阶段最大的转化漏斗。

---

## 第二阶段：让记忆更聪明（2周内）

### P2 · 记忆质量
- [ ] **自动去重** — 当前 `conflict` 检测需要手动 `force=true`，改为：高相似度记忆自动合并/更新
- [ ] **记忆衰减** — 旧记忆降低权重，基于最后访问时间和重要度
- [ ] **记忆优先级** — `confidence` 字段已有，需在前端展示 + 搜索排序生效
- [ ] **批量导入** — 从 Claude/ChatGPT 导出 JSON/Markdown，一键导入 Moltable

### P2 · 搜索增强
- [ ] **混合搜索** — 向量相似度 + 全文搜索 + 标签过滤，一次查询三类命中
- [ ] **搜索摘要** — 返回结果带相似度分数和上下文片段，而非仅 ID
- [ ] **时间范围过滤** — "上周关于 FOST 的记忆"

### 原因
> 当前能存能查，但记忆质量决定了用户是否愿意持续使用。100 条无价值的噪音记忆不如 10 条精准相关的。

---

## 第三阶段：Persona 产品化（1个月内）

### P3 · Persona 模板
- [ ] **官方模板库** — 5-10 个预设 Persona（CFO、CEO、数据分析师、代码审查员、产品经理）
- [ ] **社区分享** — 用户可发布/下载 Persona，带评分和下载量
- [ ] **一键克隆** — 看到好用的 Persona，一键复制到自己账户

### P3 · Persona 自动生成
- [ ] **从记忆生成** — 基于用户 100+ 条记忆，自动推断偏好和风格，生成 Persona 草稿
- [ ] **从对话历史生成** — 上传聊天记录，提取行为模式

### 原因
> 当前 Persona 创建是纯手动填 JSON——这要求用户理解 system prompt 工程。模板化将 Persona 从"功能"变成"产品"。

---

## 第四阶段：团队协作（2个月内）

### P4 · 共享记忆
- [ ] **团队记忆库** — Team 套餐核心卖点：共享记忆在成员间流转
- [ ] **权限控制** — 谁可以读/写团队记忆、哪些 Persona 能访问
- [ ] **活动日志** — 谁在什么时候访问了什么记忆（audit_logs 表已就绪）

### P4 · 企业功能
- [ ] **SSO/OIDC 登录**
- [ ] **用量仪表板** — CEO 视角：团队总记忆量、活跃 Persona、API 调用趋势
- [ ] **数据导出合规** — 一键导出所有数据（GDPR 准备）

### 原因
> Free→Pro→Team 的升级路径需要实际差异化的团队功能来驱动。当前三条定价线几乎没有产品上的差异。

## 第五阶段：平台生态（远期）

### P5 · 接入更多 AI 平台
| 平台 | 接入方式 | 难度 |
|------|---------|:--:|
| ChatGPT | 浏览器插件（Chrome Extension） | 中 |
| Copilot | VS Code 插件 | 中 |
| Cursor | MCP 或插件 | 低 |
| 本地 Ollama | MCP 直连 | 低 |

### P5 · 自有品牌 Agent
- [ ] **@moltable Agent** — 一个轻量包装，预装 Moltable 记忆+Persona，用户开箱即用
- [ ] **Web UI 对话界面** — 不依赖第三方 AI 平台，直接在 moltable.ai 用（但 LLM 推理在 Agent 端）

---

## 🚫 明确不做的事

| 事项 | 原因 |
|------|------|
| 自研 LLM/Moltable 自带推理 | 偏离基础设施定位 |
| 聊天机器人 | 已有 1000 个，不差这一个 |
| 自训练模型 | 成本巨大，用户的数据是他们的 |
| 移动 App | Web PWA 足够，移动端需求未验证 |
