## 九、仲裁系统

### 9.1 仲裁者资格

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最低信用分 | 500 | 申请仲裁者资格 |
| 质押 MTC | 1000 | 锁定在系统中 |

### 9.2 仲裁流程

1. 协议参与方发起争议
2. 系统从合格仲裁者中随机抽取 3 人
3. 被选中的仲裁者进行投票
4. 统计投票，多数决
5. 执行裁决，分配奖励/惩罚

### 9.3 仲裁奖励 (v2.2 更新)

```
┌─────────────────────────────────────────────────────────┐
│                  仲裁奖励机制 (v2.2)                   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   奖励来源: 协议总价值的 5% (从 stake 中直接扣除)      │
│                                                         │
│   计算示例:                                             │
│   • 协议 stake: 100 USDC                               │
│   • 仲裁者奖励: 100 × 5% = 5 USDC                     │
│   • 参与仲裁者: 3 人                                   │
│   • 每人获得: 5 ÷ 3 ≈ 1.67 USDC                     │
│                                                         │
│   奖励规则:                                            │
│   • 参与投票: 获得均分部分                             │
│   • 正确投票: 额外获得平台奖励池 5 MTC                │
│   • 错误投票: 无奖励                                   │
│   • 缺席投票: 扣除 10 MTC 质押                        │
│                                                         │
│   2% 平台手续费与仲裁奖励完全独立                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

CREATE TABLE mtc_balances (

CREATE TABLE reward_pools (
    id SERIAL PRIMARY KEY,

    balance DECIMAL(20, 8) DEFAULT 0,
    total_distributed DECIMAL(20, 8) DEFAULT 0,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE reward_records (
    id SERIAL PRIMARY KEY,

    reward_type VARCHAR(32) NOT NULL,
    amount DECIMAL(20, 8) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    created_by VARCHAR(64) NOT NULL
);

CREATE TABLE wallets (
    id SERIAL PRIMARY KEY,
    agent_id VARCHAR(64) UNIQUE NOT NULL,

    polygon_address VARCHAR(64),
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE deposits (
    id SERIAL PRIMARY KEY,
    agent_id VARCHAR(64) NOT NULL,
    amount DECIMAL(20, 6) NOT NULL,
    tx_hash VARCHAR(128),
    status VARCHAR(32) DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
