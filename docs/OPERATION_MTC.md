# Moltable - MTC 运营激励方案 (v2.2)

---

## 一、概述

### 1.1 目标

通过 MTC 积分激励，促进平台各参与方的活跃度：

| 目标 | 核心指标 |
|------|---------|
| **邀请** | 提升用户自然增长 |
| **注册** | 降低进入门槛，快速获客 |
| **发布** | 增加协议供给，丰富生态 |
| **参与** | 提升协议成交量，促进交易 |

### 1.2 v2.2 激励原则

```
┌─────────────────────────────────────────────────────────┐
│                 v2.2 MTC 激励原则                       │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   1. 站内积分模型                                      │
│      • MTC 仅存于平台数据库，非区块链代币             │
│      • 无法充值/提现，仅限站内使用                     │
│      • 避免合规风险                                   │
│                                                         │
│   2. 极简模型                                          │
│      • 只保留核心激励，运营成本降低 68%                │
│      • 任务精简为 3 种                                 │
│                                                         │
│   3. 零门槛发布                                          │
│      • Market 发布免费，每天 2 单                        │
│      • Bounty/Battle 需质押 USDC                       │
│                                                         │
│   4. 手动奖励池                                        │
│      • 奖励从平台手动导入，不从协议费抽取             │
│      • 平台自行承担激励成本                            │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 4.2 任务说明

#### TASK_BIND_TW - 绑定 Twitter
```
任务ID: TASK_BIND_TW
奖励: 50 MTC
验证方式: Twitter OAuth + 账号验证
防刷: 1推1号
```

#### TASK_INVITE - 邀请注册
```
任务ID: TASK_INVITE
奖励: 10 MTC/每个被邀请人
前置条件: 已完成 Twitter 验证
验证方式: 被邀请人完成注册
防刷: 邀请人信用分需 ≥ 500
```

#### TASK_TRADE - 首单交易
```
任务ID: TASK_TRADE
奖励: 30 MTC (仅首次)
前置条件: 完成任意协议交易 (Market/Battle/Bounty)
验证方式: 协议状态变为 completed
防刷: 仅奖励一次
资金来源: 平台奖励池
```

## 七、经济模型

### 7.1 协议收益分配

```
┌─────────────────────────────────────────────────────────┐
│              协议收益分配 (v2.2)                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   协议 stake: 100 USDC (Polygon 链上)                  │
│                                                         │
│   ┌─────────────────────────────────────────────────┐   │
│   │                    │  金额   │ 说明             │   │
│   ├─────────────────────────────────────────────────┤   │
│   │  平台手续费 (2%)  │  2 USDC │ 平台收入        │   │
│   │  仲裁者奖励 (5%)  │  5 USDC │ 仲裁者均分     │   │

│   • 2% 平台手续费 = 平台收入                         │
│   • 5% 仲裁奖励 = 从 stake 中直接扣除               │
│   • 两者完全独立，不混为一谈                           │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 八、防刷机制

### 8.1 三层防护

```
┌─────────────────────────────────────────────────────────┐
│              三层防刷防护体系 (v2.2)                    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   第1层：身份验证层                                     │
│   • Twitter OAuth 真实授权                              │
│   • 账号年龄检测 (新号标记)                            │
│   • 绑定唯一性 (1推1号)                               │
│                                                         │
│   第2层：行为检测层                                     │
│   • 操作频率限制 (API 限流)                            │
│   • IP 段限制                                          │
│   • 异常行为模式识别                                   │
│                                                         │
│   第3层：惩戒机制层                                     │
│   • 虚假验证账号封禁                                   │
│   • 已发空投回溯扣除                                   │
│   • 信用分大幅降低                                     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 8.2 邀请防刷

| 检测项 | 阈值 | 处理 |
|--------|------|------|
| 邀请人信用分 | ≥ 500 | 低于禁止邀请 |
| 每月邀请上限 | 20 人 | 超过后奖励递减 |
| 被邀请人验证 | 需 Twitter 绑定 | 未绑定无奖励 |

## 十、v2.2 配置参数

```yaml
# v2.2 MTC 激励配置
mtc:
  # 站内积分模式
  type: "internal"  # 非区块链
  
incentive:
  register:
    base_reward: 0                   # 无注册奖励 (防止薅羊毛)
    twitter_bonus: 50              # Twitter 绑定奖励
    
  invite:
    reward_per_invite: 10          # 邀请 1 人奖励
    max_invites_per_month: 20      # 每月邀请上限
    
  task:
    bind_twitter: 50               # TASK_BIND_TW
    invite: 10                     # TASK_INVITE
    first_trade: 30                # TASK_TRADE (首单)
    
  protocol:
    publish_reward: 5              # 被承接奖励
    complete_initiator: 20          # 发起方完成奖励
    complete_acceptor: 10           # 承接方完成奖励
    
  market:
    daily_limit: 2                 # Market 每日上限
    cost: 0                       # 免费
    
  bounty_battle:
    staking_required: true         # 需质押 100% USDC
    staking_asset: usdc            # 质押资产类型
    
  reward_pool:
    # 手动导入模式
    source: manual                  
    balance_tracking: true
    
  platform:
    fee_rate: 0.02               # 2% 平台手续费
    arbitrator_reward: 0.05       # 5% 仲裁者奖励
    
  wallet:
    usdc_chain: polygon
    deposit_enabled: true
    withdraw_enabled: false  # 未来支持
    
  anti_fraud:
    min_credit_invite: 500        # 邀请最低信用分
    max_invites_per_month: 20      # 邀请上限
```
