## 二、技术选型

| 层 | 技术 | 理由 |
|----|------|------|
| **后端框架** | Python + FastAPI | MCP SDK 原生 Python 支持；Hermes 生态一致 |
| **数据库** | PostgreSQL + pgvector | 向量检索+关系查询一体；无需单独的向量数据库 |
| **嵌入模型** | text-embedding-3-small (OpenAI) | 便宜($0.02/1M tokens)、1536维、够用 |
| **MCP 协议** | mcp Python SDK | Anthropic 官方，支持 stdio 和 HTTP transport |
| **前端** | Next.js + Tailwind | 快速开发；控制台不需要复杂状态管理 |
| **浏览器插件** | Chrome Extension Manifest V3 | 标准方案 |
| **部署** | Docker + Railway/Railway | 单容器即可，无需 K8s |
| **缓存** | Redis (可选) | Phase 2 引入，降低 embedding 成本 |

### 为什么选 Python 而不是 Go

1. MCP 官方 Python SDK 最成熟
2. Hermes 生态（Skill、Plugin）都是 Python
3. AI/ML 生态（embedding、RAG）Python 最强
4. MVP 速度优先，性能瓶颈在 embedding API 不在语言

### 为什么用 pgvector 而不是 Pinecone/Weaviate

1. 减少运维依赖——一个数据库解决所有存储
2. pgvector 已足够成熟（支持 HNSW 索引）
3. MVP 阶段数据量不超过 100 万条记忆
4. 语义搜索 + 结构化过滤一体查询

## 三、数据库 Schema

```sql
-- ============ 用户与认证 ============

CREATE TABLE users (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    email         TEXT UNIQUE NOT NULL,
    name          TEXT,
    timezone      TEXT DEFAULT 'Asia/Shanghai',
    language      TEXT DEFAULT 'zh',
    created_at    TIMESTAMPTZ DEFAULT now(),
    updated_at    TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE api_keys (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
    key_hash      TEXT NOT NULL,              -- SHA-256 of mtb_live_xxx
    key_prefix    TEXT NOT NULL,              -- mtb_live_XXXX (前12位，用于UI显示)
    name          TEXT,                       -- "Hermes on Mac"
    permissions   TEXT[] DEFAULT '{read,write}', -- read/write/admin
    last_used_at  TIMESTAMPTZ,
    expires_at    TIMESTAMPTZ,
    created_at    TIMESTAMPTZ DEFAULT now(),
    revoked_at    TIMESTAMPTZ                 -- NULL = active
);

-- ============ Identity & Persona ============

CREATE TABLE personas (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
    name          TEXT NOT NULL,              -- "战略顾问"
    type          TEXT NOT NULL DEFAULT 'constructed', -- constructed | mapped
    description   TEXT,
    system_prompt TEXT,                       -- 人格定义
    traits        JSONB DEFAULT '{}',         -- {"style":"麦肯锡","risk":"激进","detail":"高"}
    model_preference TEXT,                    -- "claude-sonnet" | "deepseek" | null(跟随Agent)
    version       INTEGER DEFAULT 1,
    parent_id     UUID REFERENCES personas(id), -- fork来源
    is_active     BOOLEAN DEFAULT true,
    memory_count  INTEGER DEFAULT 0,
    created_at    TIMESTAMPTZ DEFAULT now(),
    updated_at    TIMESTAMPTZ DEFAULT now()
);

-- Entity 版本历史（Git式）
CREATE TABLE persona_versions (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    persona_id    UUID REFERENCES personas(id) ON DELETE CASCADE,
    version       INTEGER NOT NULL,
    diff          JSONB,                      -- 与上一版本的差异
    changelog     TEXT,                       -- 用户写的更新说明
    snapshot      JSONB NOT NULL,             -- 该版本的完整快照
    created_at    TIMESTAMPTZ DEFAULT now()
);

-- ============ Memory ============

CREATE TABLE memories (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
    content       TEXT NOT NULL,
    category      TEXT NOT NULL,              -- preference/decision/fact/project/relationship
    source        TEXT,                       -- "hermes" | "claude" | "chatgpt" | "manual"
    confidence    REAL DEFAULT 1.0,           -- 0.5=推测, 1.0=确定
    embedding     vector(1536),              -- pgvector 嵌入
    tags          TEXT[] DEFAULT '{}',
    is_archived   BOOLEAN DEFAULT false,
    created_at    TIMESTAMPTZ DEFAULT now(),
    updated_at    TIMESTAMPTZ DEFAULT now()
);

-- HNSW 索引（加速向量检索）
CREATE INDEX ON memories USING hnsw (embedding vector_cosine_ops);

-- 全文索引（加速关键词搜索）
CREATE INDEX ON memories USING gin (to_tsvector('simple', content));

-- 按用户+分类查询
CREATE INDEX ON memories (user_id, category);

-- ============ Context（活跃上下文）============

CREATE TABLE projects (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
    name          TEXT NOT NULL,
    description   TEXT,
    is_active     BOOLEAN DEFAULT false,
    created_at    TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE decisions (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
    project_id    UUID REFERENCES projects(id),
    content       TEXT NOT NULL,
    decided_at    TIMESTAMPTZ DEFAULT now()
);

-- ============ 审计日志 ============

CREATE TABLE audit_logs (
    id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id       UUID REFERENCES users(id) ON DELETE CASCADE,
    api_key_id    UUID REFERENCES api_keys(id),
    action        TEXT NOT NULL,              -- auto_provision/search_memory/save_memory/consult_persona
    details       JSONB,
    ip_address    TEXT,
    created_at    TIMESTAMPTZ DEFAULT now()
);
```

## 四、核心流程

### 4.1 auto_provision() — Agent 自动配置

```
Agent调用 auto_provision(api_key)
    ↓
1. 验证 API Key → 获取 user_id
2. 查询 users 表 → profile (name, role, timezone, language)
3. 查询 memories WHERE category='preference' → 行为规则列表
4. 查询 memories WHERE category='preference' AND tags 含 'rule' → 工作规则
5. 查询 projects WHERE is_active=true → 当前项目
6. 查询 decisions ORDER BY decided_at DESC LIMIT 10 → 最近决策
7. 查询 personas WHERE is_active=true → 可用 Persona 列表
8. 查询 memories WHERE category IN ('fact','project') → 核心知识
    ↓
返回结构化上下文
    ↓
Agent 据此配置自己的行为模式
    ↓
记录 audit_log: action=auto_provision
```

### 4.2 search_memory() — 语义检索

```
Agent调用 search_memory(query="淄博车检", top_k=5)
    ↓
1. 调用 embedding API → 将 query 转为向量
2. SELECT * FROM memories
   WHERE user_id=$1
   ORDER BY embedding <=> $2   -- cosine distance
   LIMIT $3
3. 可选：加 category 过滤
    ↓
返回: [{id, content, category, source, relevance_score}]
    ↓
记录 audit_log: action=search_memory
```

### 4.3 save_memory() — 记录记忆

```
Agent调用 save_memory(content="赵偏好表格", category=preference, confidence=1.0)
    ↓
1. 调用 embedding API → 将 content 转为向量
2. 冲突检测：
   SELECT * FROM memories
   WHERE user_id=$1 AND category=$2
   ORDER BY embedding <=> $3 LIMIT 3
   → 如果存在 cosine_similarity > 0.9 → 返回冲突提醒
3. INSERT INTO memories
4. 如果 category=decision → 同步写入 decisions 表
    ↓
记录 audit_log: action=save_memory
```

### 4.4 consult_persona() — Persona 问答

```
Agent调用 consult_persona(persona_id="xxx", question="如何进入东南亚市场？")
    ↓
1. 查询 persona → 获取 system_prompt + traits
2. 查询 memories WHERE category IN ('fact','decision','preference')
   → 构建 Persona 专属上下文
3. 调用 LLM（使用 persona.model_preference 或默认模型）
   system_prompt = persona定义 + 用户上下文
   user_message = question
4. 返回 Persona 的独立回答
    ↓
记录 audit_log: action=consult_persona
```

## 五、MCP Server 设计

### Transport 模式

| 模式 | 场景 | 端口 |
|------|------|------|
| stdio | 本地 Agent（Claude Desktop、Cursor）| — |
| HTTP (SSE) | 远程 Agent（云端 Hermes）| 8001 |

### Tool 清单

```
auto_provision()         → 一站式配置，返回完整用户上下文
search_memory()          → 语义检索记忆，支持分类过滤
save_memory()            → 记录新记忆，自动冲突检测
update_memory()          → 更新已有记忆
list_personas()          → 列出用户的所有 Persona
consult_persona()        → 向指定 Persona 提问
create_persona()         → 创建新 Persona（Phase 2）
get_current_context()    → 获取当前活跃项目和最近决策
set_active_project()     → 设置当前工作项目
```

## 六、部署架构

```
Docker Compose (单机)
├── moltable-api      (FastAPI, port 8000)
├── moltable-mcp      (MCP Server, port 8001)
├── moltable-web      (Next.js, port 3000)
```

## 七、安全设计

| 层 | 措施 |
|----|------|
| 传输 | TLS 1.3 全链路 |
| 认证 | API Key (SHA-256 哈希存储，只在前12位明文显示) |
| 鉴权 | 每条记忆绑定 user_id，API 中间件强制检查 |
| 审计 | 所有 MCP 调用记录 audit_logs |
| 数据隔离 | 多租户通过 user_id 严格隔离 |
| 可撤销 | API Key 随时吊销，立即生效 |
| 导出 | 用户可一键导出全部数据 (JSON/CSV) |
| 删除 | 用户可一键删除全部数据 (硬删除) |
