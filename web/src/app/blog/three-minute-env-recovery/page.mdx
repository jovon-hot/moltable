## 第一步：注册并安装 CLI

去 [moltable.ai/register](/register) 注册，30 秒完成。然后一条命令安装 CLI：

```bash
curl -sL https://moltable.ai/install.sh | bash
```

**Free 套餐就够用**——3 个 Agent 实例、100MB，日常开发完全覆盖。

## 第二步：在第一台电脑上同步

在你现有的主力机上，登录账号并初始化你的 Agent（下面的命令会生成文件级备份，作为在线同步之外的兜底快照）：

```bash
# 初始化备份配置
moltable backup init

# 打包上传
moltable backup push
```

文件级备份自动包含：

✅ SOUL.md、AGENTS.md、USER.md（人格与项目规则）
✅ memories/（项目背景、偏好、历史决策）
✅ skills/（沉淀的技能与工作流）
✅ config.yaml（MCP 配置，密钥脱敏）
✅ 自动排除对话流水账（state.db/WAL/FTS）和密钥（.env/*.key）

## 第三步：在新电脑上一键恢复

换到新 Mac 之后，你只需要几行命令：

```bash
# 一条命令安装 Moltable CLI
curl -sL https://moltable.ai/install.sh | bash

# 拉取并还原备份源
moltable backup pull
```

这条命令自动完成：检测 Python → 下载 CLI → 添加到 PATH。之后登录账号，调用 `auto_provision` 即可把上下文与 Persona 一键同步到新电脑；也可以运行 `moltable backup pull` 走文件级备份兜底还原。**不需要手动编辑任何 JSON。**

恢复前可以用 `moltable sources` 确认你的 Agent 列表，每个 Agent 的调教成果都带版本号，随时可以回滚。

## 原理：Moltable 的灵魂三层架构

为什么 3 分钟能恢复这么多东西？因为 Moltable 不同步对话流水账，同步的是**你的 Agent 身份与记忆**：

### Profile（本体）

你是谁——账户与设备维度

### Soul（化身：人格 + 记忆，在线同步）

角色特征、回答风格、项目记忆、技能沉淀

### 凭证（DID + VC，即将推出）

可验证身份，为灵魂资产加上归属

技术上，同步引擎按 sha256 内容寻址增量传输，只有变化的部分才上传；文件级备份则生成 bundle + manifest 落在对象存储——这就是"3 分钟"的来源：不是魔法，是在线同步 + 增量备份的设计。

## 常见问题

### Q: 我的密钥安全吗？

Moltable 同步与文件级备份都会自动排除密钥文件（.env / *.key），config.yaml 里的 MCP 配置密钥脱敏后才会打包，所有传输使用 TLS 加密。

### Q: 能自托管吗？

能。Moltable 是 MIT 开源协议。Clone 仓库 → pip install → python main.py，3 条命令跑起来。

### Q: 免费版够用吗？

对于个人开发者，Free 套餐（$0，3 个 Agent 实例 / 100MB）足够日常开发。多实例、团队协作可升级 Pro（$3/月，10 个 Agent 实例 / 1GB）或 Ultra（$5/月，100 个 Agent 实例 / 10GB），仅月付。
